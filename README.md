# pixelboos
A web app that lets users create accounts and customize their characters and play various mini board games with pixel art graphics

## Features
- User registration and login system
- Multiple mini games in one application
- Custom character selection
- Retro pixel graphics
- Score tracking for Pacman, Rock Paper Scissor and Snake game
- Responsive and user-friendly interface

## Technologies Used
  - HTML
  - CSS
  - Javascript
  - Express.js
  - MongoDB
  - Electron

## Deployment
- Backend hosted on Render
- Application release is distributed through Github Releasees

## How to Use
1. Go to the Releases section of this repository
2. Download the latest release.
3. Install the application.
4. Launch the app and create account or log in.
5. Select a game and start playing.
